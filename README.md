# Обезличенная переносимая копия

В копии отсутствуют папка .env, токен, Telegram ID владельца, база данных,
отчёты, рабочие журналы, кэш и персональная история исходного проекта.
Используй собственного Telegram-бота и собственную авторизацию Codex через ChatGPT.
Не запускай две копии с одним токеном одновременно.

Первый запуск: Setup.command → собственный токен и числовой Telegram ID → Start.command.
Папка .env создаётся только при настройке. Python 3.9+ и Codex CLI нужны на новом Mac.
Фоновый режим: Enable Background.command создаёт новый LaunchAgent с актуальным путём
к этой копии. Он не использует службу исходного проекта и сейчас не установлен.
Отключение: Disable Background.command. Сначала проверь ручной запуск.

Ниже сохранена техническая документация исходной системы. Упоминания проверок
в среде разработки описывают ограничения разработки, а не настройку нового Mac.
Раздел о ранее установленном автозапуске не означает, что служба копии уже установлена.

# Новости Германии через Telegram и Codex

Локальный бот для одного владельца. Источники: @meduzalive, @ejdailyru,
@forbesrussia. Темы: электроэнергетика Германии, её внутренняя и внешняя политика.
Python 3.9+, без сторонних Python-пакетов. Анализ через установленный Codex CLI,
авторизованный в ChatGPT. Отдельного API-ключа нет. Доступен фоновый автозапуск.

## Фоновая работа после входа в macOS

По запросу пользователя установлен файл
`~/Library/LaunchAgents/local.germany-news-bot-clean-copy.plist`.
Один раз открой `Enable Background.command` и закрой старую ручную копию бота
через Ctrl+C, если она ещё работает. Автоматическая активация из среды разработки
не удалась: launchctl bootstrap вернул Input/output error. Текущее состояние службы
из этой среды не подтверждено. При следующем входе macOS читает установленный plist.

После активации launchd запускает бот без окон и перезапускает при завершении.
Выбирай период с компьютера или телефона. ChatGPT должен оставаться авторизованным
в Codex CLI в этой же учётной записи macOS. Вход в macOS после перезагрузки обязателен.
`caffeinate -i` предотвращает автоматический сон при бездействии, пока работает бот.
Закрытая крышка, ручной сон, выключение и потеря сети прерывают доступность.
Расход энергии выше из-за предотвращения сна; для длительной работы подключи питание.
Экран может гаснуть и блокироваться.

Журналы: `data/service.log`, `data/service-error.log` и DEVELOPMENT_HISTORY.txt.
Отключение, включая будущие входы в macOS: `Disable Background.command`.
Ручной Start.command и фоновую службу одновременно запускать не следует.
Ниже описан альтернативный ручной режим; при фоновой работе Терминал не нужен.

## Настройка

1. Создай бота у @BotFather командой `/newbot`.
2. Узнай свой числовой Telegram ID (например, у @userinfobot; не токен).
3. Открой `Setup.command`: введи токен скрытым вводом и свой ID.
   Файлы `.env/bot_token` и `.env/owner_id` остаются только на Mac.
   Для показа скрытых файлов в Finder: Cmd+Shift+точка.
4. Проверь `codex login status`. Должен быть вход через ChatGPT.
   При необходимости выполни `codex login` и войди в аккаунт с подпиской.
5. Открой `Start.command`, затем открой созданного бота и отправь `/start`.

Если macOS не открывает .command двойным кликом, запусти в Терминале:

```sh
cd ~/Projects/germany-news-bot
python3 -m app.main --setup
python3 -m app.main
```

В ручном режиме окно с программой должно оставаться открытым, компьютер — работать и иметь сеть.
Кнопка Telegram запускает сбор и анализ, пока программа запущена. Сама кнопка
не может включить выключенную программу на Mac. Для автозапуска используй фоновый режим выше.

## Периоды и результаты

24 часа, 3 дня и 7 дней — скользящие интервалы до момента нажатия.
Свои даты: `2026-11-10 2026-11-16`, обе даты включены. Часовой пояс по умолчанию
Europe/Moscow; можно поменять в config.json, например на Europe/Berlin.
Максимальный период — 90 дней; предел страниц и размер пакетов тоже в config.json.
Первый запрос «с прошлого анализа» предлагает сначала выполнить обычный анализ.
Контрольная дата обновляется только после полного сбора и успешной отправки.
Исторический запрос не сдвигает её назад. Отметка — общая, не отдельная для каждого периода.

Одинаковые события объединяются с деталями источников и ссылками. Детали помечены
ключами channel/id. Противоречия должны сохраняться с указанием источника.
Это модельный пересказ: абсолютную сохранность всех деталей гарантировать нельзя;
проверяй оригиналы. Программа валидирует структуру и реальные идентификаторы ссылок.
Загрузка файлов, распознавание изображений/видео и чтение внешних статей не включены.
Публичный просмотр может скрывать публикации: даже успешное достижение границы
не гарантирует совпадения с полной историей в приложении Telegram.

Анализ использует лимиты Codex в твоём аккаунте ChatGPT. Программа явно требует
ChatGPT-авторизацию и удаляет переменные API-ключей из окружения запуска анализа.
Каждый запрос — отдельный Codex exec; контекст этой беседы ему недоступен.
Codex запускается read-only, без пользовательского config, с отключёнными shell и
web search; текст новостей передаётся через stdin, а не как shell-команда.
Политика проекта запрещает модели инструменты и доступ к приложениям.

## Диагностика и восстановление

- `DEVELOPMENT_HISTORY.txt` — история разработки и этапов работы, без секретов.
- `data/state.sqlite3` — посты, запросы, контрольная дата, offset Telegram.
- `data/report-N.json` — результаты до отправки; сохраняются и при сбое доставки.
- После аварии незавершённые запросы помечаются interrupted при следующем запуске.
- Доставку после сетевого сбоя программа не повторяет автоматически: часть сообщений
  могла быть принята Telegram. Повторный запрос может дать повторы.
- Два экземпляра одновременно запускать нельзя: действует файловая блокировка.
- Если уже настроен webhook, приложение останавливается, не меняя чужую настройку.
- Старые текстовые команды старше 10 минут пропускаются; накопленные нажатия кнопок
  могут быть обработаны при запуске. Нажимай кнопки после запуска программы.

Остановка: Ctrl+C. При активном анализе программа дожидается его окончания.
База и отчёты не очищаются автоматически. Секреты не попадают в Git и журналы.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют разбор вложенной разметки, переходы по страницам, частичный сбор,
границы периода, смену часового пояса, выдуманные ссылки и деление длинного текста.
Для проверки живого анализа нужен рабочий Codex; для полной доставки — токен и ID.
В среде разработки вложенный запуск Codex был отклонён системой с ошибкой
`failed to initialize in-process app-server client: Operation not permitted`.
Это не подтверждение работоспособности анализа: его нужно проверить из обычного
Терминала macOS. Вход через ChatGPT на машине подтверждён командой login status.
